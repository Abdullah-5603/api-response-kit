# Support

Thank you for using api-response-kit! Here are the best ways to get help:

## Documentation

- **README.md** - Quick start and API reference
- **CONTRIBUTING.md** - Development setup and guidelines
- **CHANGELOG.md** - Version history and changes

## Getting Help

### Bug Reports

If you've found a bug, please [open a bug report](https://github.com/Abdullah-5603/api-response-kit/issues/new?template=bug_report.md) with:

- A clear description of the issue
- Steps to reproduce
- Expected vs. actual behavior
- Your environment (Node.js version, npm version, api-response-kit version)

### Feature Requests

Have an idea for a new feature? [Submit a feature request](https://github.com/Abdullah-5603/api-response-kit/issues/new?template=feature_request.md) with:

- A clear description of the feature
- Use cases and examples
- Why this feature would be valuable

### Questions & Discussions

For general questions and discussions, open a [GitHub Discussion](https://github.com/Abdullah-5603/api-response-kit/discussions) or check existing issues.

### Security Issues

⚠️ **Do not** open public issues for security vulnerabilities. Please refer to [SECURITY.md](SECURITY.md) for responsible disclosure.

## Community

- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md)
- Search for existing issues before opening a new one
- Provide as much context as possible
- Use code examples and formatted code blocks
